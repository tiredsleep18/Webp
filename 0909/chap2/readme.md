

1. HTML5 페이지 기본 구조 및 태그 특징**
기본 구조: HTML5 문서는 `<!DOCTYPE html>` 지시어로 시작하며, `<html>`, `<head>`, `<body>` 태그로 구성됩니다. 주석은 `<!-- 주석 -->` 형태로 작성하여 화면에 출력되지 않게 합니다.
태그 구성: 시작 태그와 종료 태그가 쌍을 이루는 경우와 시작 태그만 있는 단일 태그(예: `<br>`)가 있습니다. 태그와 속성은 대소문자를 구분하지 않습니다.

2. 텍스트 작성 및 꾸미기**
제목 및 단락: `<h1>` ~ `<h6>` 태그로 문단 제목을 달 수 있고, `<p>` 태그로 단락을 나눕니다. 수평선은 `<hr>`, 줄바꿈은 `<br>` 태그를 사용합니다.
텍스트 서식 및 포맷: 입력한 공백과 줄바꿈을 그대로 출력하려면 `<pre>` 태그를 사용합니다. 텍스트 강조 및 스타일링을 위해 `<b>` (진하게), `<strong>` (중요한), `<i>` / `<em>` (이탤릭/강조), `<mark>` (하이라이팅) 등의 태그를 제공합니다.
특수 문자(엔터티): `<` (`&lt;`), `©` (`&copy;`), 공백 (`&nbsp;`) 등의 기호 및 심볼은 엔터티나 코드값을 이용해 입력합니다.

3. 블록 태그와 인라인 태그
블록 태그: 항상 새 라인에서 시작하며 한 라인을 독점하여 사용합니다 (예: `<div>`, `<p>`, `<h1>`, `<ul>`).
인라인 태그: 블록 태그 내에 삽입되어 줄을 바꿈 없이 일부로 출력됩니다 (예: `<span>`, `<strong>`, `<a>`, `<img>`).

4. 메타데이터 삽입
메타데이터: 웹 페이지를 설명하는 데이터로, `<head>` 태그 내에 작성됩니다.
주요 태그:
  * `<base>`: 웹 페이지의 기본 URL 및 윈도우 지정.
  * `<link>`: 외부 CSS 스타일 시트 등 외부 자원 연결.
  * `<meta>`: 웹 페이지의 저작자(`author`), 설명(`description`), 검색 키워드(`keywords`), 문자 인코딩(`charset="utf-8"`) 설정.

5. 이미지, 리스트, 표 작성**
이미지 삽입**: `<img>` 태그의 `src` 속성에 이미지 경로를 지정하며, 이미지 대체 텍스트(`alt`), 너비/높이(`width`/`height`)를 지정할 수 있습니다.
리스트 만들기**:
    순서 있는 리스트: `<ol>`과 `<li>` 사용 (`type` 속성으로 마커 변경 가능).
    순서 없는 리스트: `<ul>`과 `<li>` 사용.
    정의 리스트: `<dl>`, `<dt>` (용어), `<dd>` (설명) 사용.
표 만들기 (`<table>`)**: 표 제목(`<caption>`), 헤더 그룹(`<thead>`), 데이터 그룹(`<tbody>`), 바닥 그룹(`<tfoot>`) 구조로 구성되며, 행(`<tr>`), 열 제목(`<th>`), 데이터 셀(`<td>`)을 통해 표를 완성합니다.

6. 하이퍼링크 및 인라인 프레임**
하이퍼링크 (`<a>`)**: `href` 속성에 이동할 URL을 지정하며, `target` 속성(`_blank`, `_self` 등)을 통해 페이지가 열릴 윈도우/탭을 제어합니다.
앵커 및 다운로드**: `id` 속성을 활용해 동일한 페이지 내 특정 위치로 이동하는 앵커를 만들 수 있고, `download` 속성을 추가하여 파일 다운로드 링크를 제공할 수 있습니다.
인라인 프레임 (`<iframe>`)**: 웹 페이지 내에 다른 HTML 페이지를 내장하는 태그로, `srcdoc` 속성을 이용해 직접 HTML 코드를 삽입할 수도 있습니다.

7. 미디어 삽입 (`<audio>`, `<video>`)**
* 별도의 외부 플러그인 없이 오디오 및 비디오를 재생할 수 있는 HTML5 표준 태그입니다.
* `controls` (제어 버튼 표시), `autoplay` (자동 재생), `loop` (반복 재생) 등의 속성을 지원하며, `<source>` 태그를 이용해 다중 파일 포맷을 지정할 수 있습니다.
