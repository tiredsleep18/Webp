
### **1. CSS3 작성 및 적용 방식**
HTML 문서에 CSS3 스타일 시트를 적용하는 방식은 크게 3가지가 있습니다.

* **`<style>` 태그에 작성**: `<head>` 태그 내에 작성하여 웹 페이지 전체에 적용합니다.
* **`style` 속성에 작성 (인라인)**: 특정 HTML 태그에만 직접 스타일을 적용합니다.
* **외부 `.css` 파일 불러오기**: 별도의 파일로 저장한 후 `<link>` 태그나 `@import` 문으로 불러와 스타일의 재사용성을 높입니다.

```html
<!-- 외부 스타일 시트 불러오기 -->
<link rel="stylesheet" type="text/css" href="mystyle.css">

<style>
  /* @import로 외부 파일 불러오기 */
  @import url("mystyle.css");

  /* <style> 태그 내 스타일 정의 */
  body { background-color : linen; color : blueviolet; }
</style>

<!-- 인라인 style 속성 사용 -->
<p style="color : blue; font-size : 15px;">인라인 스타일 적용</p>
```

---

### **2. 스타일 규칙 (상속 및 오버라이딩)**
* **스타일 상속**: 자식 태그는 부모 태그의 스타일(예: 글자 색상 등)을 자동으로 상속받습니다.
* **스타일 합치기(Cascading) 및 오버라이딩**: 동일한 태그에 여러 스타일이 중첩될 경우, 우선순위(**인라인 `style` 속성 > `<style>` 태그 / 외부 시트 > 브라우저 기본값**)가 높은 스타일이 이전 스타일을 덮어씁니다.

---

### **3. 다양한 셀렉터(Selector) 활용**
HTML 태그의 모양을 꾸밀 대상을 선택하는 셀렉터의 주요 종류입니다.

* **태그 이름 셀렉터**: 지정한 태그 전체에 적용.
* **class 셀렉터 (`.`)**: 그룹 단위로 여러 태그에 동일 스타일 적용.
* **id 셀렉터 (`#`)**: 페이지 내 유일한 특정 태그 선택.
* **자식(`>`) 및 자손(공백) 셀렉터**: 부모-자식 관계나 하위 자손 관계의 태그 선택.
* **가상 클래스 셀렉터 (`:`)**: 마우스 오버(`:hover`), 링크 상태(`:visited`), 첫 글자(`:first-letter`) 등 특정 조건에 스타일 적용.

```css
/* 태그 이름 셀렉터 */
h3, li { color : brown; }

/* class 셀렉터 */
.warning { color : red; }

/* id 셀렉터 */
#list { background : mistyrose; }

/* 자식 및 자손 셀렉터 */
div > strong { background : yellow; } /* div의 직계 자식 strong */
ul strong { color : dodgerblue; }      /* ul의 자손 strong */

/* 가상 클래스 셀렉터 */
li:hover { background : yellowgreen; }
```

### **4. 텍스트, 폰트 및 색상 표현**
* **색상 표현**: **16진수 코드**(`#8A2BE2`), **RGB 10진수**(`rgb(138, 43, 226)`), **표준 색 이름**(`blueviolet`)의 3가지 방식을 지원합니다.
* **텍스트 및 폰트 제어**: `text-align`(정렬), `text-indent`(들여쓰기), `text-decoration`(줄 표시) 및 `font-family`, `font-size`, `font-weight` 등의 프로퍼티를 사용합니다.

```css
p {
  color : #8A2BE2;
  font : italic bold 20px consolas, sans-serif; /* font 단축 프로퍼티 */
  text-align : justify;
  text-indent : 2em; /* 2글자 들여쓰기 */
}

a {
  text-decoration : none; /* 하이퍼링크 밑줄 제거 */
}
```

### **5. 박스 모델 (Box Model)**
모든 HTML 태그 요소는 사각형 박스로 처리되며, **콘텐츠(Content), 패딩(Padding), 테두리(Border), 여백(Margin)**으로 구성됩니다.

* **테두리 스타일**: `border-style`(`solid`, `dotted`, `dashed`, `groove` 등) 및 단축 프로퍼티 `border` 지원.
* **둥근 모서리 및 이미지 테두리**: `border-radius`로 모서리를 둥글게 하거나, `border-image`로 이미지를 테두리로 활용.

```css
div.box {
  width : 200px;
  height : 100px;
  padding : 20px;            /* 안쪽 여백 */
  border : 5px solid peru;   /* 테두리 단축 프로퍼티 */
  margin : 30px;             /* 바깥 여백 */
  border-radius : 15px;      /* 둥근 모서리 */
}
```

---

### **6. 배경, 그림자 및 커서 효과**
* **배경 제어**: `background-color`, `background-image`, `background-repeat`, `background-position`, `background-size` 지정.
* **그림자 효과**: `text-shadow`(텍스트 그림자), `box-shadow`(박스 그림자)로 시각적 입체감 표현.
* **마우스 커서**: `cursor` 프로퍼티로 마우스가 위치할 때의 커서 모양 지정(`pointer`, `crosshair`, `help` 등).

```css
/* 배경 단축 프로퍼티 및 박스 그림자 */
div.card {
  background : skyblue url("media/spongebob.png") center/100px 100px no-repeat;
  box-shadow : 10px 10px 5px skyBlue;
  cursor : pointer;
}

/* 텍스트 그림자 */
h1 {
  text-shadow : 3px 3px 5px red; /* 수평 수직 흐림반경 색상 */
}
```
