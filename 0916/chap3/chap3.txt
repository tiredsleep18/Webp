
### **1. HTML5 문서 구조화와 시맨틱 태그**
* **문서 구조화의 필요성**: 기존에는 `<div>`나 `<table>` 태그를 주로 사용했으나, 이는 웹 문서의 의미나 구조를 전달하기 어려웠습니다. HTML5에서는 검색 엔진이 정보 검색을 용이하게 수행하고 웹 문서의 가치를 극대화할 수 있도록 의미 있는 **시맨틱 웹(Semantic Web)** 구조화 방식이 도입되었습니다.
* **주요 시맨틱 태그**:
  * `<header>`: 페이지/섹션의 머리말
  * `<nav>`: 목차나 하이퍼링크 모음
  * `<section>`: 문서의 장(Chapter) 또는 절 구분
  * `<article>`: 본문과 연관된 독립적인 콘텐츠 영역 (블로그 포스트, 기사 등)
  * `<aside>`: 사이드바, 주요 기사 옆의 팁이나 댓글 영역
  * `<footer>`: 꼬리말 (저자, 저작권 정보 등)
* **디자인과의 분리**: 시맨틱 태그는 문서 구조와 의미만 지정할 뿐, 위치나 색상, 모양은 **CSS3**를 사용하여 지정해야 합니다.
* **기타 블록/인라인 시맨틱 태그**:
  * `<figure>` / `<figcaption>`: 본문에 삽입하는 그림, 소스코드, 실행 결과 등을 블록화
  * `<details>` / `<summary>`: 상세 정보를 접고 펼칠 수 있는 Q&A 형태의 블록
  * **인라인 태그**: `<mark>`(텍스트 하이라이팅), `<time>`(시간 표시), `<meter>`(범위/비율), `<progress>`(진행 상황)
* **HTML5 제거 태그**: 문서 구조 형성을 저해하는 `<big>`, `<center>`, `<font>`, `<frame>`, `<frameset>` 등은 HTML5 표준에서 폐기되었습니다.

### **2. 웹 폼 (Web Form)**
* **폼의 기본 개념**: 사용자로부터 로그인, 회원가입, 검색 등의 입력을 받아 웹 서버로 전달하는 구조입니다.
* **`<form>` 태그의 핵심 속성**:
  * `action`: 폼 데이터를 처리할 웹 서버 응용프로그램의 URL 지정
  * `method`: 데이터 전송 방식 (`GET` 방식 또는 `POST` 방식)
* **다양한 입력 요소 (Form Controls)**:
  * **텍스트 입력**: `<input type="text">`, 비밀번호용 `<input type="password">`, 여러 줄 입력용 `<textarea>`, 추천 선택 항목을 보여주는 `<datalist>`
  * **선택형 입력**: 다중 선택이 가능한 `<input type="checkbox">`, 그룹 중 하나만 선택하는 `<input type="radio">`, 드롭다운 방식의 `<select>`/`<option>`
  * **버튼 요소**: `<input type="submit|reset|button">` 및 `<button>` 태그
  * **`<label>` 태그**: 캡션 텍스트와 폼 요소를 하나로 묶어 클릭 범위를 넓히고 명확성을 높여줍니다.
* **HTML5 추가 폼 요소 및 기능**:
  * **색상 및 시간**: `<input type="color">`, 날짜/시간 입력 전용 태그 (`date`, `month`, `week`, `time`, `datetime-local`)
  * **숫자 입력**: 스핀버튼 형태의 `<input type="number">`, 슬라이드 바 형태의 `<input type="range">`
  * **형식 검사 텍스트**: 이메일(`email`), URL(`url`), 전화번호(`tel`), 검색어(`search`) 입력창 및 힌트를 보여주는 `placeholder` 속성
  * **그룹화**: `<fieldset>`과 `<legend>`를 사용해 관련된 폼 요소들을 테두리 상자로 묶음
